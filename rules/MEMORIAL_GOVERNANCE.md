# Context Memorial Governance Rules (표준 거버넌스 규격)

> 본 문서는 AI 코딩 에이전트 환경(Antigravity IDE, Claude Code, Cursor 등)의 시스템 프롬프트나 프로젝트 룰 문서(`GEMINI.md`, `AGENTS.md`)에 그대로 포함하여 사용하는 표준 가드레일 명세입니다.

---

## 1. 3대 정본 문서 역할 및 고유 식별자 체계 (Three-Tier Memorial Model)

1. **`task.md` / `task_completed.md`**: 작업 식별자 `TSK-{자연수}` (자릿수 패딩 없음, 예: `TSK-1`, `TSK-26`).
   - 모든 개발 작업 및 Git 커밋의 단일 정본(Single Source of Truth).
   - `task.md`는 현재 활성 작업만 관리하며, 파일 크기를 **5KB 이하**로 상시 유지한다.
   - 신규 태스크 번호는 전체(완료 포함) 태스크 중 `최대 번호 + 1`을 영구 불변으로 발급한다.
   - **표준 서식 규격**: 마크다운 블록 형식(`### TSK-X. 작업명` 하위 `- **상태**: [상태]`, `- **대상 영역**: \`경로\``) 또는 불릿 한 줄 형식(`- [상태] **TSK-X. 작업명**`)을 모두 공식 지원한다.
2. **`patterns_index.md` / `patterns/`**: 패턴 식별자 `P-{순차증가번호}` (예: `P-01`, `P-45`).
   - 에이전트 전용 재사용 규칙, 트러블슈팅 및 설계 솔루션 지식 베이스.
   - 모든 실제 패턴은 `patterns/` 하위에 개별 마크다운 파일로 샤딩 보관하며, `patterns_index.md`에는 1행 요약 메타데이터만 등록한다.
3. **`project_changelog.md`**: 아키텍처 식별자 `LOG-{순차증가번호}` (예: `LOG-01`, `LOG-06`).
   - 거시 아키텍처 및 시스템 결정 기록 (ADR). 단순 버그나 화면 수정은 기록하지 않고 아키텍처 결정 사항만 최상단에 누적(Prepend)한다.

---

## 2. 작업 라이프사이클 및 Git 원자적 커밋 거버넌스

1. **작업 상태 전이**:
   - `[ ]` (대기) -> `[진행 중]` -> `[커밋 대기]` (빌드/검증 완료) -> `[x]` (커밋 완료).
2. **조기 이관 절대 금지**:
   - 터미널에서 실제 `git commit` 완료 SHA 해시를 획득하기 전에는 `task.md`에서 `task_completed.md`로 조기 이관을 절대 금지한다.
   - 완료 이관 시 커밋 해시 필수 명기: `- [x] **TSK-X. 작업명** (Commit: abc1234)`.
3. **작업 단위 원자적 커밋 (Task-Centric Commits)**:
   - 무관한 수정사항을 한 번에 스테이징하는 일괄 커밋(`git add .`)을 금지한다.
   - `scripts/group-status.cjs`를 구동하여 `task.md`, `project_changelog.md`, `patterns_index.md`에 명시된 범위에 따라 파일들을 작업 단위별로 분할 커밋한다.

---

## 3. 지식 베이스 온디맨드 검색 원칙 (Just-In-Time Grep - 0토큰 원칙)

1. **전수 통조회 100% 금지**:
   - 에이전트 세션 시작 시 `patterns/` 하위 파일이나 방대한 히스토리 문서를 무조건 읽어들이는 행위를 엄격히 금지한다.
2. **선별 Grep 검색**:
   - 작업 키워드로 `patterns_index.md`의 요약 열만 정밀 Grep(`grep_search`)하고, 매칭된 특정 샤딩 파일(`patterns/P-XX-*.md`)만 핀포인트로 읽어들인다. 매칭이 없으면 즉시 종료한다.
3. **바이패스 프리픽스**:
   - 사용자 프롬프트에 `/스킵`, `/태스크` 프리픽스가 있거나 단순 질의/설정/문서 작업 시 지식 검색 단계를 100% 생략한다.
4. **사후 증류 (Post-Task Distillation)**:
   - 검증이 완료된 범용 재사용 솔루션에 한해 다음 불변 번호(`P-XX`) 샤딩 파일을 신설하고 `patterns_index.md`에 1행을 추가 등록한다.

---

## 4. 거시 아키텍처 ADR 조건부 열람 원칙

1. **평소 조회 금지**: 평소 작업 시 `project_changelog.md`를 조회하지 않는다 (0토큰).
2. **3대 조건부 이벤트 발생 시에만 제한적 조회**:
   - 1) 전역 인프라/설정 수정
   - 2) 회귀 결함 역추적
   - 3) 원격 대규모 머지 직후
   - 위 3대 조건 발생 시에만 최상단 1~2개 블록(40라인 이내)만 슬라이스 조회한다.
