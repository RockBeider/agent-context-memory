# Project Changelog & Architecture Decision Records (ADR)

> [!IMPORTANT]
> **거버넌스 원칙 (Rule)**:
> 1. 본 문서는 단순 화면 개발이나 개별 버그 수정이 아닌, **거시 아키텍처 결정 사항(ADR) 및 시스템 주요 변경**만 누적 기록합니다.
> 2. 신규 결정 사항은 최신순으로 상단에 누적(Prepend)하며, 고유 식별자 `LOG-{순차증가번호}` 체계를 사용합니다.
> 3. AI 에이전트는 평소 본 파일을 전수 조회하지 않으며, 전역 아키텍처 수정이나 대규모 머지 직후에만 최상단 30~40줄을 조건부로 조회합니다.

### [LOG-01] [2026-10-19] 3계층 컨텍스트 메모리얼 시스템 도입

- **관련 커밋/브랜치**: init / main
- **결정 배경 및 목적**:
  - 장기 프로젝트 진행 시 AI 에이전트의 컨텍스트 윈도우 초과 및 정보 소실 문제를 해결하기 위해 3계층 메모리얼 모델을 정립함.
- **아키텍처 결정 사항**:
  - L1(단일 활성 태스크: `task.md`), L2(지식 베이스 색인 및 샤딩: `patterns_index.md`, `patterns/`), L3(완료 아카이브: `task_completed.md`) 계층 분리.
  - `group-status.cjs` 커밋 엔진을 도입하여 태스크 정본 기반의 원자적 커밋 자동화 확립.
- **예상 효과**:
  - 에이전트의 세션 시작 시 컨텍스트 토큰 소모를 0에 가깝게 억제하고 지식 검색 효율 극대화.
