# Agent Context Memory Task Master (작업 단일 정본)

> [!IMPORTANT]
> **거버넌스 원칙 (Rule)**:
> 1. 본 문서는 현재 활성화된 작업만을 관리하는 단일 정본(Single Source of Truth)입니다. (최대 5KB 유지, 최근 완료: `없음`, 현재 활성: `없음`)
> 2. 태스크 ID(`TSK-XXXXXX`)는 영구 불변 6자리 단축 ID(Crockford Base32)로 `acm task add`, `acm id`, 또는 MCP로 발급합니다(기존 `TSK-{N}` 호환).
> 3. 상태 라이프사이클: `[ ]` (대기) -> `[진행 중]` -> `[커밋 대기]` (검증 완료) -> `[x]` (`npm run acm:commit` 실행 시 `task-completed.md`로 자동 이관).
> 4. `[커밋 대기]` 전환 시 반드시 하위 불릿에 **목적**, **수행결과(파일별 상세 내역)**, **대상영역(실제 수정된 모든 파일 경로 백틱 명시)** 3요소를 기록해야 `group-status.cjs`가 커밋 본문을 생성하고 자동 이관합니다.

> **작업 기록 양식 샘플 (Sample Format - 실제 작업 아님)**:
> 아래 블록은 작성 예시입니다. 실제 작업 등록 시 `## 활성 태스크 목록` 하단에 발급된 `TSK-XXXXXX` ID로 작성하십시오.
> ```markdown

> ```
