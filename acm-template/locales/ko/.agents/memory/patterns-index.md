# Learned Patterns Index (지식 베이스 경량 색인표)

> [!IMPORTANT]
> **0토큰 온디맨드 검색 원칙 (Just-In-Time Grep)**:
> 1. AI 에이전트는 본 파일이나 하위 패턴 디렉터리를 무조건 전수 통조회하지 않습니다.
> 2. 작업 키워드로 본 파일의 요약 열을 `grep_search`하여 매칭된 샤딩 파일(`patterns/P-*-*.md`)만 선별 로딩합니다.
> 3. 아래 `P-00`은 작성 양식 샘플입니다. 실제 지식 패턴 증류 시 **`P-XXXXXX`**(`acm pattern add` / `acm id pattern` / MCP)를 발급하여 샤딩 파일을 생성하고 본 인덱스에 추가하십시오.
